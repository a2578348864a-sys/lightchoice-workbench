# 认证与访问控制

## 当前模型：Local Owner

- 运行时只有一个身份：本机 Owner（`LOCAL_OWNER_PRINCIPAL`），不再签发访问密码。
- 服务默认绑定 `127.0.0.1`；没有访客、多租户或配额体系。
- 历史文档中的 Visitor / 沙箱 / 配额概念已退役，不要再按那套模型实现。

## 写请求门禁

1. `resolveAccessContext`：校验 Host 可信；mutating 请求校验 Origin/Referer 同源。
2. 路由层：`writeAuth` / `requireOwnerOnly`。
3. 服务层：业务前置条件（状态、版本、内容哈希、幂等键）。

跨站写返回 403；未通过业务前置条件返回 409/422 与稳定错误码。

## 不做的事

- 不为开源发布临时重构认证（当前没有公网部署计划）。
- 不把前端禁用当作鉴权；所有门禁必须在服务端。
