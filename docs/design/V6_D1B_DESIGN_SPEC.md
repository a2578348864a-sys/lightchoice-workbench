# V6 阶段 D · D1-B 设计规范（内部实施文档）

## 风格锚点

个人 AI 商品研究工作台：Notion 的内容组织 + Linear 的状态/操作层级 + Material 的组件一致性。
亮底、清爽、专业；青春绿只用于主操作与完成态，不铺大面积渐变。

## 色板（沿用并收紧现有 token）

| 角色 | 值 |
| --- | --- |
| 背景 app-bg | `#f6f8f7`（slate-50 微调偏绿灰） |
| 面板 surface | `#ffffff` |
| 墨色 ink | `#0f172a`；次级 `#475569`；辅助 `#64748b` |
| 主绿 brand | `#059669`（brand-600）；深 `#047857`；浅底 `#ecfdf5` |
| 待核实 amber | `#b45309` / 底 `#fffbeb` |
| 错误/危险 rose | `#be123c` / 底 `#fff1f2` |
| 分隔线 | `rgba(15,23,42,0.08)` |

状态必须「颜色 + 文字」双编码，不允许只靠颜色。

## 字号阶梯（D0-009 修复基线）

| 层级 | 规格 |
| --- | --- |
| 页面 H1 | 26–28px / 700 |
| 区块标题 H2 | 18–20px / 700 |
| 卡片标题 H3 | 15–16px / 600 |
| 正文/表单 | 15–16px（长说明行高 1.65） |
| 表格单元 | 13–14px |
| 辅助说明 | 12–13px |
| 技术编号 | 11–12px（仅哈希/ID） |

不机械全局放大：表格与工具栏单独定义。

## 间距与控件

8 / 12 / 16 / 24 / 32px；控件高 36–40px（dense 表单 32–36）；卡圆角 12px；主分区圆角 16px。

## 布局系统

- 左侧导航固定：工作台 → 产品开发流程（采集/市场/深研/需求单）→ 辅助（监控、飞书、诊断）→ 保留工具（Listing 文案/图片）。
- 页面骨架：PageHeader（eyebrow + H1 + 描述 + 主操作）→ 上下文条（可选）→ 内容区。
- 1440×900 主视口；内容最大宽不受限但长文列宽受控。

## D1-B 范围（本轮落地）

1. 全局排版与 token（globals.css / tokens.css 微调 + DataTable 字号）。
