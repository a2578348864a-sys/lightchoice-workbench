# 产品概览

## 定位

面向 Amazon 美国站的证据驱动型商品研究与产品开发决策工作台。

它不是自动选品器，也不替人做决定；它把"看到什么、依据是什么、谁拍的板"记录下来。

## 四个阶段

| 阶段 | 用户要回答的问题 | 系统提供 |
|---|---|---|
| 01 市场采集 | 这个市场/商品到底有什么可观察的事实？ | 样本、证据、缺失字段清单 |
| 02 市场研究 | 这个市场值得进入吗？ | 样本充分性、缺口知悉、代表商品、Market Gate |
| 03 商品深研 | 这个商品值不值得做？改什么？ | 需求/竞争/VOC 研报、风险门禁、AI 建议 |
| 04 需求单 | 要做的话，做成什么样？ | 规格、对比、验证计划、版本与批准门禁 |

## 谁适合用

- 自己做 Amazon 产品开发、愿意为判断负责的个人或小团队；
- 需要把研究过程留痕、可复盘、可交接的人；
- 不接受"AI 直接给结论"的黑盒工具的人。

## 不适合

- 需要多人协作/权限分级/公网 SaaS 的团队（当前不支持）；
- 希望全自动选品、自动上架的用户。
